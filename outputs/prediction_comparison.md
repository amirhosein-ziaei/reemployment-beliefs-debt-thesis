# Incremental predictive value of reemployment beliefs (G-P2 Phase 2)

> **EXPLORATORY — PENDING INDEPENDENT HUMAN VALIDATION.** Generated by `code/06_prediction.py`
> (`outputs/exploratory/prediction_*.csv`, `prediction_tables.md`). Design fixed in advance in
> `outputs/model_specification.md` §7; run once, with no tuning. The target is a **reported
> subjective expectation** (next month's Q30new), not delinquency or default.

## Design

| Element | Choice |
| - | - |
| Unit | Analysis-sample person-month t whose person responds in calendar month **t+1 exactly**, with a valid Q30new (any employment status at t+1) |
| Target | Q30new at t+1 |
| Baseline (all dated t) | Q30new_t, Q13new_t, tenure_t (survey count), 11 month-of-year dummies |
| Expanded | Baseline + fd10_t (= (100 − Q22new_t)/10) + centred fd10_t × loss10_t, with centring constants taken from the training data |
| Model | OLS with intercept; predictions clipped to [0, 100]; no fixed effects with a lagged outcome |
| Eval 1, person held out | 5 folds assigned by person (seed 20261010). No person is in both training and test |
| Eval 2, forward time | Expanding window. For each test year 2016–2025, train on pairs whose *target* month is ≤ December of the previous year; test on pairs dated in that year |
| Uncertainty | Eval 1: person-cluster bootstrap (999). Eval 2: calendar-month block bootstrap (999). Fitted models held fixed; 95% percentile intervals |

## Rotating-panel entry, exit and gaps

| Analysis rows at t | n | Share |
| - | - | - |
| Next calendar month observed with valid Q30 (prediction sample) | 87,320 | 80.6% |
| Next response only after a gap of ≥ 2 months (excluded; no next-month target) | 6,723 | 6.2% |
| No later response at all (rotation exit or attrition) | 14,345 | 13.2% |

* Only exact next-month targets are used, so gaps are never bridged.
* Entry is handled because each pair needs only information at t.
* Exit is handled because rows without a t+1 response have no target.
* Attrition is not random: higher Q30new predicts a missing next month (S6b in
  `measurement_sensitivity.md`). Prediction results describe respondents who stay at least one
  more month.

## Results

Δ = baseline − expanded (positive = adding job-finding beliefs helps).

| Evaluation | n | RMSE base → expanded | ΔRMSE (pp) [95% CI] | Relative ΔRMSE [95% CI] | ΔMAE (pp) [95% CI] | Relative ΔMAE | Classification |
| - | - | - | - | - | - | - | - |
| 1. Person held out | 87,320 (12,874 persons) | 13.602 → 13.599 | 0.0024 [0.0004, 0.0045] | **0.018%** [0.003%, 0.033%] | 0.0062 [0.0026, 0.0098] | 0.084% | **negligible** |
| 2. Forward years 2016–2025 | 70,030 (117 test months) | 13.494 → 13.491 | 0.0030 [0.0016, 0.0045] | **0.022%** [0.012%, 0.033%] | 0.0108 [0.0086, 0.0130] | 0.150% | **negligible** |
| 2b. Forward, test persons unseen in training | 48,681 | 13.981 → 13.978 | 0.0031 [0.0016, 0.0048] | 0.022% [0.011%, 0.034%] | 0.0105 [0.0076, 0.0132] | 0.139% | negligible |

The prespecified rule calls the gain **material** if relative RMSE improvement ≥ 1% with CI
lower bound > 0, and **negligible** if the CI upper bound is < 1%. The observed upper bounds
are about 0.03%, some 30 times below the 1% line.

* **By fold:** gains in 4 of 5 folds, one slightly negative.
* **By forward test year:** gains in 9 of 10 years (2025's is essentially zero), and a
  negative value in 2020 (`prediction_by_fold_and_year.csv`).
* The improvement is consistently tiny and statistically distinguishable from zero. It is not
  practically useful.

**What a 0.003pp RMSE reduction means.** The typical next-month forecast error is about
13.5pp. Adding Q22new moves it by three thousandths of a point. MAE improves slightly more
(0.08–0.15%), consistent with a small gain concentrated among typical respondents rather than
large errors.

## Full-sample expanded model (for interpretation only)

| Term | Coefficient |
| - | - |
| Q30new_t | 0.731 |
| Q13new_t (per pp) | 0.040, i.e. 0.40 per 10pp |
| tenure_t | −0.042 |
| fd10_t (per 10pp lower finding prob.) | 0.086 |
| centred fd10 × loss10 | −0.006 |

* Next month's payment expectation is dominated by its current value (persistence 0.73).
* Current job-loss belief adds about 0.4pp per 10pp.
* Current finding difficulty adds under 0.1pp per 10pp.

## Answer

Adding reemployment beliefs **does not materially improve** out-of-sample prediction of
next-month debt-payment expectations, either for new people or for later calendar years. The
increment is precisely estimated and negligible.
